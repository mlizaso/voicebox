## Entry points

`POST /transcribe` returns text for an uploaded file. `POST /captures` adds the
higher-level recording/transcript archive workflow; dictation and in-app capture
use it. A voice sample's transcription can help fill its reference text, but the
sample API still requires the exact confirmed transcript.

The STT protocol and registry are in `backend/backends/__init__.py`; the service
wrapper is `backend/services/transcribe.py`. MLX/PyTorch implementations own their
model loading, preprocessing, and transcription behavior. Performance depends on
model, device, and audio; there is no fixed cross-platform speed multiplier.

## Request

```bash
curl --fail http://127.0.0.1:17493/transcribe \
  -F 'file=@recording.wav' -F 'model=turbo' -F 'language=es'
```

Use multipart **`file`**, **`model`**, and optional **`language`**. `model_size`,
`audio`, and `whisper-turbo` are not the corresponding field/value names here.
Valid model selectors are `base`, `small`, `medium`, `large`, and `turbo`.
Explicit language hints are `en`, `zh`, `ja`, `ko`, `de`, `fr`, `ru`, `pt`, `es`,
and `it`; omit the hint for auto-detection. Capture settings also accept `auto`.

Multipart parameters are validated before audio processing. File extension,
upload size, duration, channels, sample rate, and decoded-size limits are enforced
by the request and audio boundaries. Current limits and responses are available
in the generated API schema and `routes/transcription.py` / `routes/captures.py`.

```json
{"text":"Texto transcrito.","duration":3.5}
```

## Reference samples

The UI can call transcription, let the user correct the result, and submit
`file` plus `reference_text` to `/profiles/{id}/samples`. The reference text must
match the sample; accepting a wrong transcript changes the cloning input.
Reference samples have their separate 30-second/1,000-character limits.

## Lifecycle and errors

The selected model is loaded lazily, shared through the STT backend, and may be
unloaded or switched through model management. Captures store the resulting text
and original audio; retrying transcription is different from regenerating TTS.
Bad model/language metadata is rejected, missing speech may return no useful
transcript, and model download/device/capacity failures should be reported as such.
