Effects process existing audio with Pedalboard and can save the result as a
generation version. They change the sound; preview a chain before applying it,
and avoid applying mastering again to a finished audiobook.

## Effects and presets

`GET /effects/available` returns the authoritative effect registry with parameter
names, defaults, and bounds. It includes chorus/flanger, reverb, delay, compressor,
gain, filters, and pitch shift. A chain is an ordered JSON list; each type and
parameter is validated before processing.

Presets save reusable chains in the database. Built-in presets are read-only;
users can create and maintain their own. Fetch registry definitions rather than
copying parameter limits into another client.

## Source selection and versions

Generation creates the original audio and may produce a processed default
version when effects are requested. Applying effects later accepts an optional
`source_version_id`, which must belong to the same generation. Without one, the
route prefers a clean version and falls back to the generation's current audio
for legacy records.

Versions record the audio path, label, effect chain, source lineage, and default
selection. Files live beneath the backend's `generations/` directory; database
paths are authoritative because original, imported, and processed files have
different naming patterns.

- Setting the default updates the generation's public audio pointer.
- Deleting the last version is forbidden.
- A version pinned by a story or used as another version's source cannot be
  deleted until that reference is removed.
- Deleting an eligible default promotes the first remaining version in stable
  creation order. Shared audio files remain while another record owns them.

New generation records also preserve chunk size, crossfade, and normalization
for replay. See [history](/developer/history) for retry and regeneration behavior.

## Processing and recovery

Preview and saved-version paths share `backend/services/effects_processing.py`
for bounded source reads and processing. Preview returns temporary audio without
creating a version; response cleanup releases its files. Saved output is staged
and published with database ownership checks and deletion-journal recovery.
Cancellation and failure must release temporary files and reservations without
removing audio owned by a surviving record.

## API

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/effects/available` | Effect definitions and bounds |
| GET / POST | `/effects/presets` | List or create presets |
| GET / PUT / DELETE | `/effects/presets/{preset_id}` | Read or maintain a preset |
| POST | `/effects/preview/{generation_id}` | Preview without saving a version |
| GET | `/generations/{generation_id}/versions` | List versions |
| POST | `/generations/{generation_id}/versions/apply-effects` | Save a processed version |
| PUT | `/generations/{generation_id}/versions/{version_id}/set-default` | Select active audio |
| DELETE | `/generations/{generation_id}/versions/{version_id}` | Delete an eligible version |
| GET | `/audio/version/{version_id}` | Fetch a version's audio |

Preview and apply requests use `effects_chain`, `label`, `set_as_default`, and
optional `source_version_id`. See the [API reference](/api-reference) for the full
request schema and bearer authentication.

## Code map and extension points

| Path | Responsibility |
| --- | --- |
| `backend/utils/effects.py` | Effect registry, validation, and DSP construction |
| `backend/services/effects_processing.py` | Shared processing, limits, scratch lifetime |
| `backend/services/effects.py` | Preset persistence |
| `backend/services/versions.py` | Version ownership, defaults, and deletion |
| `backend/routes/effects.py` | Preview, publication, and REST endpoints |
| `app/src/components/Effects/` | Chain editor, presets, and previews |

To add an effect, extend the registry with supported numeric parameters and
check that the editor represents them correctly. Validate parameter rejection,
preview cleanup, publication failure, and version lineage as relevant. Do not
change default processing order or existing generation settings as a side effect.
