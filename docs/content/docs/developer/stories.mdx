title: "Stories & Timeline"
description: "Clip ownership, editing, playback, and bounded story export"

Stories arrange generated or imported clips on a timeline. Items store a
generation reference, optional pinned version, track, start time, trims, and
per-clip volume. Editing a story does not destructively rewrite its source audio.

## Data and ownership

`Story` and `StoryItem` live in `backend/database/models.py`. A pinned
`version_id` must belong to the item's generation. Unpinned items follow the
generation's active audio; pin a version when a story must retain a specific take.
Deletion checks protect referenced generations and versions.

Times use milliseconds. `start_time_ms` positions a clip, while `trim_start_ms`
and `trim_end_ms` remove leading and trailing playback without editing the file.
`track` identifies a timeline row; `volume` is a linear multiplier from 0.0 to
2.0. Moving, trimming, splitting, duplicating, and replacing a version validate
the resulting item and story limits before persisting changes.

## Client playback

The shared timeline uses the platform audio contract and loads active clips
instead of decoding an entire long story in advance. Media reads retain the
selected server, bearer token, cancellation, and size bounds. Native and browser
playback capabilities differ, so changes need checks on the supported adapter.

## Export

`GET /stories/{story_id}/export-audio` produces a mixed **mono 24 kHz PCM WAV**.
The service validates source ownership, pinned versions, durations, trims, and
resource limits before rendering. It decodes and resamples in blocks and mixes
through disk-backed scratch storage, then removes temporary output after the
response completes. Cancellation and startup cleanup recover abandoned exports.

Current limits include **1,000 items** and a **24-hour timeline**. Existing
generated clips can be up to that timeline limit; new direct audio imports have
a separate **30-minute upload limit**. Aggregate source decoding and sample counts are also bounded;
being under the timeline limit alone does not guarantee that an export fits.
Disk reservations account for scratch and final output. Invalid or missing audio
fails visibly instead of silently skipping a clip.

Stories export a mixed WAV. Book ingestion, chapters, final audiobook containers,
and durable book-wide resume belong to the optional private audiobook workspace
described in the repository README and `docs/AUDIOBOOKS.md`.

## API map

| Method | Path | Purpose |
| --- | --- | --- |
| GET / POST | `/stories` | List or create stories |
| GET / PUT / DELETE | `/stories/{story_id}` | Read, update, or delete a story |
| POST | `/stories/{story_id}/items` | Add a generation |
| DELETE | `/stories/{story_id}/items/{item_id}` | Remove a clip |
| PUT | `/stories/{story_id}/items/times` | Update clip positions |
| PUT | `/stories/{story_id}/items/reorder` | Reorder clips |
| PUT | `/stories/{story_id}/items/{item_id}/move` | Move position/track |
| PUT | `/stories/{story_id}/items/{item_id}/trim` | Change trims |
| PUT | `/stories/{story_id}/items/{item_id}/volume` | Change gain |
| POST | `/stories/{story_id}/items/{item_id}/split` | Split a clip |
| POST | `/stories/{story_id}/items/{item_id}/duplicate` | Duplicate a clip |
| PUT | `/stories/{story_id}/items/{item_id}/version` | Change pinned version |
| GET | `/stories/{story_id}/export-audio` | Export the mix |

Use the [API reference](/api-reference) for request bodies and authentication.

Focused regressions include `test_story_item_integrity.py`,
`test_story_audio_export_bounds.py`, and `test_version_delete_atomicity.py` under
`backend/tests/`. Also check seeking, simultaneous clips, and cancellation in
the actual UI when changing playback.
