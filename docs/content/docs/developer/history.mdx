## Ownership

`backend/database/models.py` defines generation/version records;
`backend/services/history.py` owns history operations. Generation publication
is coordinated by `services/generation.py` and recovery helpers. Audio paths are
stored relative to the configured data root; do not infer an active version from
`<generation-id>.wav` alone.

## Metadata and replay

Generation records include text, profile, language, seed, instructions, engine,
model size, status/error, source, favorites, timestamp, and exact-contract hashes.
`max_chunk_chars`, `crossfade_ms`, and `normalize_audio` are nullable columns:

- New requests store their accepted settings in the existing transaction.
- Retry uses the stored settings and seed.
- Regenerate creates a new take, retaining the settings but not promising the same waveform.
- Old NULL records use legacy retry/regenerate defaults.
- Imported raw audio has no TTS request and cannot be replayed as synthesis.

`HistoryResponse` extends `GenerationResponse` and adds `profile_name`, keeping
the shared metadata contract in one place. Additive migrations must remain
idempotent and preserve old values.

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/history` | Filter/page history |
| GET | `/history/stats` | Aggregate counts/durations |
| GET / DELETE | `/history/{generation_id}` | Read/delete one record |
| POST | `/generate/{generation_id}/retry` | Retry a failed TTS request |
| POST | `/generate/{generation_id}/regenerate` | New take of completed TTS |
| GET | `/history/{generation_id}/export` | Portable generation archive |
| GET | `/history/{generation_id}/export-audio` | Active audio export |
| POST | `/history/import` | Validate/import a generation archive |
| GET | `/generations/{generation_id}/versions` | Available versions |
| GET | `/audio/{generation_id}` | Active generation audio |
| GET | `/audio/version/{version_id}` | Specific version audio |

The generated API reference supplies complete request schemas and parameters.
Story items may pin a version; deletion guards preserve referenced content and
reject operations that conflict with active generation.

## Archives

Generation ZIPs preserve selected audio bytes and supported metadata, including
engine/model, seed, timestamp, source, and replay settings. Import uses the same
bounded generation/profile validation as live requests, validates the archive
and audio, and publishes a new owned record. Older archives have compatibility
defaults. Archive import does not grant an exact-runtime guarantee for future synthesis.

Back up a stopped complete data root for full history/story relationships, or
export individual items for portability. See [storage](/overview/storage-and-backup).
