## Prerequisites

Use Python 3.12+ (setup prefers 3.12/3.13), Bun, Git, and `just`. Desktop builds
also need Rust and native Tauri dependencies. On macOS use the full Xcode toolchain
for native asset compilation. The private audiobook GUI additionally needs Tk and
its own renderer environment/FFmpeg installation.

## Install and run

```bash
git clone https://github.com/mlizaso/voicebox.git
cd voicebox
just setup
just dev
```

The recipes install `backend/venv`, special engine dependencies, pinned MLX
packages on Apple Silicon, and the main Bun workspace. The private ignored
`voice-profile/` assets and separate `docs/` dependencies are not installed by
this setup. Do not substitute a plain requirements install for the engine setup.

| Command | Behavior |
| --- | --- |
| `just dev` | Backend and Tauri desktop development |
| `just dev-web` | Backend and browser development |
| `just dev-backend` | Backend with reload on 17493 |
| `bun run dev:web` | Browser UI only |
| `bun run dev` | Desktop development UI only |
| `just --list` | Complete recipe reference |

If the desktop detects an existing listener, explicitly connect only to the
server you started. Vite normally uses 5173; the Python backend uses 17493.

## Stable generation and data

```bash
backend/venv/bin/python -m backend.main \
  --host 127.0.0.1 --port 17493 --data-dir /absolute/path/to/voicebox-data
```

Avoid reload mode for long renders. The CLI alone defaults to port 8000 and
`data/` relative to its working directory; always pass port/data root deliberately.
Use `backend\venv\Scripts\python.exe` on Windows. Packaged apps pass their OS
app-data root; the private audiobook launcher normally uses checkout `data/` and
port 17494. See [storage](/overview/storage-and-backup).

## Validate and build

```bash
bun run ci
backend/venv/bin/python -m pytest backend/tests -q
just check-python
bun run check
just build
```

CI runs app tests, import-boundary linting, TypeScript checks, and both frontend
builds. Full lint/format checks are separate and have known baseline debt.
`just build` creates sidecars and the desktop bundle; `just build-web` builds the
browser client. Native checks and platform prerequisites are listed in the root
`CONTRIBUTING.md`; docs site commands are in `docs/README.md`.

## Navigate the source

Use the [architecture guide](/developer/architecture). The root README includes
the complete directory map and the private audiobook operating steps.
The API client is handwritten under `app/src/lib/api/`; generated documentation
comes from `docs/openapi.json`, not a generated application client.
