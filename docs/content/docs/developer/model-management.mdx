## Registry and selection

`backend/backends/__init__.py` contains `ModelConfig` entries and engine helpers.
The frontend presents compatible choices through `EngineModelSelector` and
model settings. Qwen cloning uses 0.6B/1.7B; TADA uses 1B/3B. Invalid combinations
are rejected before generation. Preset profiles stay bound to their source engine.

Model weights download on demand and remain cached after unloading. Loaded model
memory, downloaded weights, profile references, and derived conditioning cache
are distinct resources.

## Cache location

Hugging Face normally uses `~/.cache/huggingface/hub/`. `HF_HOME` or `HF_HUB_CACHE`
can change it; `VOICEBOX_MODELS_DIR` sets Voicebox's hub cache override before
backend startup. `GET /models/cache-dir` reports the active path. It is separate
from the database/audio data root returned by `/health/filesystem`.

```bash
VOICEBOX_MODELS_DIR=/absolute/path/to/models \
  backend/venv/bin/python -m backend.main \
  --host 127.0.0.1 --port 17493 --data-dir /absolute/path/to/voicebox-data
```

Changing the environment does not move existing files. Use model migration or
move a stopped cache deliberately; do not confuse it with moving application data.

## Operations

| Endpoint | Purpose |
| --- | --- |
| `GET /models/status` | Registered download/load state |
| `POST /models/download` | Start a download |
| `POST /models/download/cancel` | Cancel/dismiss download work |
| `POST /models/load` | Load the selected model |
| `POST /models/unload`, `POST /models/{model_name}/unload` | Release loaded model memory |
| `DELETE /models/{model_name}` | Delete downloaded model data |
| `POST /models/migrate` | Move model cache to a chosen destination |
| `GET /models/migrate/progress` | Migration progress |
| `GET /models/progress/{model_name}` | Download progress |

See the generated API reference for request schemas. Lifecycle coordination keeps
MLX models alive until blocking work drains; cancellation must not free memory
still used by inference. Migration preflights every model conflict and rejects
symlink/junction roots or a non-directory destination before moving data. It no
longer deletes an existing destination model to make room.

Native folder controls are available only for the current local desktop server.
Remote cache paths belong to the server; manage them there.

## Runtime compatibility

Pinned MLX dependencies and the Qwen implementation fingerprint are part of the
exact-generation contract. Package upgrades, model-size changes, precision changes,
and different reference preprocessing require quality/compatibility validation.
Do not use a blind dependency upgrade as a performance fix for an in-progress book.

See [TTS generation](/developer/tts-generation),
[GPU acceleration](/overview/gpu-acceleration), and
[storage and backup](/overview/storage-and-backup).
