## Start Voicebox

Launch the desktop app, or run `just dev` from a configured source checkout.
`just dev-web` starts the backend and browser UI. For a long render, use a
stable backend without reload; see [development setup](/developer/setup).

The main repository `README.md` is the complete one-file operating guide,
including the separate private audiobook workspace.

## Create or import a voice

1. Open **Voices** and create a profile with a name and language.
2. Choose a cloned voice or an engine's preset. Preset voices need no recording.
3. For cloning, upload or record a clean reference of at most 30 seconds and
   confirm its exact transcript. The transcript limit is 1,000 characters per sample.
4. Save the profile. You can also import a profile ZIP containing metadata and
   reference audio. Profiles are stored on the currently connected backend.

See [creating voice profiles](/overview/creating-voice-profiles) for sample and
preset details. The importer restores supported profile metadata, samples, and
optional avatar; cloning exports contain reference audio, not just embeddings.

## Generate a short sample

Select the voice in the generation form, choose the compatible engine/model and
language, and enter a few sentences. Review instructions and effects. Leave
personality rewriting off if the exact text must be spoken.

Click **Generate** and follow the queued request in history. First use may need
a model download and load; generation time depends on the model, text, and device.
When complete, play the result and check pronunciation and delivery before a long run.

Normal defaults are 800 characters per chunk, 50 ms crossfade, and normalization
enabled. These are saved with new generation records and reused on replay.
Qwen cloning supports 0.6B/1.7B; TADA supports 1B/3B. Preset profiles stay bound
to the engine that supplies their voice.

## Keep or reuse the result

Download audio for playback, export a generation ZIP for its audio plus metadata,
or add the clip to a story. Regeneration makes a new take; it is not a guarantee
of the same waveform. Imported audio has no TTS request to regenerate.

See [generation history](/overview/generation-history) and
[stories](/overview/stories-editor). Full-book EPUB ingestion and resume belong
to the optional private launcher described in the repository's `docs/AUDIOBOOKS.md`.

## Find the files

Use `GET /health/filesystem` on your connected server. Development from the root
uses `./data/`; the packaged app uses its OS data directory. Profile metadata
and sample transcripts are in `voicebox.db`, sample WAVs in `profiles/{id}/`, and
audio in `generations/`. See [storage and backup](/overview/storage-and-backup).
