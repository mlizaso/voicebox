## Voice studio

Voicebox provides a shared React UI in a browser or a Tauri desktop window and a
Python backend for inference and storage. Use it to create reusable voices,
generate speech, keep versions, apply effects, and arrange clips into stories.
The desktop adds native recording, system capture, hotkeys, and paste/output
integration where supported by the platform.

## Models

| Engine | Profile kind | Model choices |
| --- | --- | --- |
| Qwen3-TTS | Cloned | 0.6B / 1.7B |
| Qwen CustomVoice | Preset | 0.6B / 1.7B |
| LuxTTS | Cloned | Registered engine variant |
| Chatterbox Multilingual | Cloned | Registered multilingual variant |
| Chatterbox Turbo | Cloned | Registered Turbo variant |
| TADA | Cloned | 1B / 3B |
| Kokoro | Preset | Registered 82M engine |

Language, instruction, preset, and device support vary by engine; use the choices
shown for that engine. Whisper Base/Small/Medium/Large/Turbo handle transcription.
A local Qwen3 LLM provides refinement and personality text generation.

MLX uses Metal on supported Apple Silicon models. Other engines use their
configured PyTorch/device paths. Model size or precision changes can change
quality; no universal speed multiplier applies to all hardware and workflows.

## Data and connections

Local processing does not require a cloud account. Explicit remote mode sends
inputs to the selected backend, and cloud login uses the configured cloud service.
The presence of login does not mean the proposed encrypted backup/sync roadmap is
implemented. See [remote mode](/overview/remote-mode) and
[storage and backup](/overview/storage-and-backup).

For this fork, the repository README is the current operating guide. Upstream
downloads and the configured updater do not necessarily contain fork changes.
The private audiobook tools are a separate ignored local workspace described in
`docs/AUDIOBOOKS.md`; they add frozen book jobs and final chaptered containers.
