## Build a story

1. Create a story in **Stories** and give it a title.
2. Add generated or imported clips, assigning speakers/tracks as needed.
3. Arrange start times; trim, split, or duplicate clips in the timeline.
4. Choose the version to pin for each clip when several takes/effects versions exist.
5. Preview the arrangement and export the mixed WAV.

The [Stories editor guide](/overview/stories-editor) covers the timeline controls.
The [developer guide](/developer/stories) explains item timing and version ownership.

Exports use bounded, disk-backed mixing with limits of 1,000 items and a
24-hour mono 24 kHz timeline. Source/import limits are separate. A browser that
cannot stream files to disk may reject an export above its 64 MiB memory limit;
use the desktop client or a browser with the supported save-file API.

## Books and resume

A story is a reusable clip arrangement. The optional private audiobook launcher
adds EPUB/text ingestion, chapter metadata, narrator demos, M4B/M4A/MP3/WAV output,
and saved book-wide progress. It is not shipped as a built-in audiobook tab.
See the repository README and `docs/AUDIOBOOKS.md` for that local workflow.
