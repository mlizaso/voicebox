## Current Compose configuration

The repository's default Compose build is CPU-based. It publishes
**`127.0.0.1:17600` on the host** to port **17493 inside the container**, so a
desktop/development backend can keep using host port 17493.
Docker on this Mac does not provide the native MLX/Metal path; use the native
backend for the private Apple Silicon audiobook workflow.

## Start

From the repository root, set a persistent token before bringing up the service:

```bash
export VOICEBOX_REMOTE_API_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
docker compose up --build -d
curl --fail -H "Authorization: Bearer $VOICEBOX_REMOTE_API_TOKEN" \
  http://127.0.0.1:17600/health
```

Retain that token securely for subsequent starts. Open `http://localhost:17600`
for the bundled web UI or connect the desktop client to
`http://127.0.0.1:17600`, supplying the token in server settings.

Container-bridge peers count as remote even when the published host port is
loopback. Compose therefore requires the token and explicitly permits HTTP on
that private bridge. Do not copy this override to a public binding. The app
accepts loopback HTTP; non-loopback connections require HTTPS.

## Persistent storage

| Mount | Container location | Contents |
| --- | --- | --- |
| `voicebox-data` named volume | `/app/data` | Database, profiles, captures, app cache |
| Host `./output` bind mount | `/app/data/generations` | Generated audio and version artifacts |
| `huggingface-cache` named volume | `/home/voicebox/.cache/huggingface` | Downloaded models |

`VOICEBOX_SHARED_GENERATIONS=1` makes the output mount host-readable while
keeping the database, profiles, captures, cache, and logs private. Back up the
data volume and output directory together while stopped. Removing Compose volumes
removes persistent data; a container rebuild alone should reuse them.

## GPU variants

The default file is CPU-only. An AMD ROCm overlay is included:

```bash
docker compose -f docker-compose.yml -f docker-compose.rocm.yml up --build -d
```

Inspect the overlay, host GPU support, and device permissions before use. It
selects the ROCm dependency path and joins the groups owning the GPU device nodes.
Installing Docker does not make a native macOS Metal model available inside it.
See [GPU acceleration](/overview/gpu-acceleration) for the native backends.

## Remote publication

Keep the supplied listener on loopback and put an HTTPS reverse proxy in front.
Configure `VOICEBOX_TRUSTED_HOSTS` for the public hostname and
`VOICEBOX_CORS_ORIGINS` for a separately hosted browser UI, in the container's
environment. Preserve public Host and HTTPS scheme and narrowly trust the proxy.
The built-in bearer check remains required; optional proxy authentication is an
additional layer. See [remote mode](/overview/remote-mode).

## Diagnose

```bash
docker compose ps
docker compose logs --tail=100 voicebox
```

Check the configured token for 401, trusted authority/origin for 403, TLS for 426,
and data/output/temp capacity for 507. Query `/health/filesystem` with the bearer
header to inspect actual container storage. Initial startup can include imports
and a first model download; keep the model volume across rebuilds.
