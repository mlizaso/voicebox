## Find a generation

History shows the currently connected server's generations: text, profile,
language, timestamp, duration, state, favorites, and available versions. Use the
available text/profile/date filters. Switching servers clears the previous
connection's cached data rather than showing another server's records.

## Actions

| Action | What it does |
| --- | --- |
| Play / download | Uses the active audio version |
| Retry | Repeats a failed TTS request with the stored seed |
| Regenerate | Creates a new take; waveform and delivery can vary |
| Apply effects | Creates an effects version with source lineage |
| Favorite | Marks the generation for filtering |
| Add to story | Reuses the generation in a timeline |
| Export ZIP | Preserves audio bytes and supported generation/profile metadata |
| Import ZIP | Validates the archive and restores a new history entry |
| Delete | Removes owned history/audio subject to active-job and story-reference checks |

New requests persist chunking, crossfade, and normalization for retry and
regeneration. Legacy records retain their previous defaults. Direct audio
imports have no original TTS request; their retry/regenerate actions are disabled.

Archive round trips retain engine, model size, seed, timestamp, source, and
replay settings. An archive is not an exact audiobook-resume bundle and does not
prove that a different installed model/runtime can regenerate identical audio.

## Storage and exports

Metadata lives in `voicebox.db`; original and version artifacts live under
`generations/` in the backend's data root. File names can carry generated IDs or
version IDs, so use the API/history entry rather than constructing a filename.

Desktop downloads stream to disk. Compatible browsers can also stream exports;
the browser fallback limits in-memory downloads to 64 MiB and reports larger
files rather than exhausting the tab.

See [storage and backup](/overview/storage-and-backup) for OS-specific paths.
An exported audio file is convenient for listening; use a ZIP or complete stopped
data-root backup when you also need metadata and references.
