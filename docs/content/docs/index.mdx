Voicebox combines cloned/preset voices, speech generation, history and effects,
stories, transcription/captures, native dictation, and MCP tools. Models run on
the selected backend: local by default, or on your configured remote server.

The repository **README.md is the one-file operating guide**, including profile
storage, startup commands, source layout, and the optional private audiobook wizard.
Upstream installers and the configured updater may not contain this fork's changes.

Normal speech requests support up to 50,000 characters with configurable chunking.
The optional private audiobook renderer adds EPUB/text ingestion, narrator demos,
book containers, and durable resume; it is not part of a fresh clone or a built-in tab.
Its operating guide is `docs/AUDIOBOOKS.md` in the repository.
